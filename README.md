# OptimalRoll

A smart dice game assistant that analyzes rolls and suggests optimal moves.

## Development target

During the MVP phase, the project is developed and tested only as a Flutter
Web application in Microsoft Edge. Android, iOS, and native desktop toolchains
are not required yet.

Install Flutter and add its `bin` directory to `PATH`, then run:

```powershell
flutter pub get
flutter analyze
flutter test
flutter run -d edge
```

The IntelliJ/VS Code launch configuration is named `OptimalRoll (Edge)`.
